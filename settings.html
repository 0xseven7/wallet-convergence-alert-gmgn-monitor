推特语音设置

聚合买入提醒已恢复为原始蜂鸣音。这里仅管理推特语音提示、默认提示音和事件筛选。

TTS 语音风格

用于未映射账号提示，以及映射到 `default.MP3` / `preset1.MP3` 的推特语音播报。

推特事件筛选

语音特别关注钱包

这套名单和 GMGN 自带星标无关。只有加入这里的钱包，后续在 follow 信息流里出现新买卖时才会触发 TTS。

黑名单钱包

黑名单钱包不会改变原有聚合与提醒逻辑，只会在 GMGN 页面里额外显示一个 ! 标记。

GMGN 外部 Hook

推特触发规则和本地事件面板共用这一组外部转发设置。浏览器只发信号，不在本地持有交易密钥。

GMGN 买入触发规则

规则命中后，插件会把账号、动作、正文、CA、链和买入数量发给你的外部服务。

新增映射

把推特 ID 或钱包标签映射到内置提示音、自定义上传音频或链接音源。

自定义音源库

支持导入本地音频 / ZIP，也支持直接填写音频链接作为提示声音来源。

规则 JSON

这里只导入导出映射规则，不包含内置音频文件。

已有映射

可以试听、编辑或删除已经保存的映射关系。
